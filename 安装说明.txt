QQ官方机器人 —— 环境一键配置（通用版）
================================================================

一、这个文件夹是干什么的
  给 Windows 机器一键装好机器人运行所需的环境：
  Python + SDK + 依赖库。装完就能去机器人目录双击「启动主控.bat」。

二、通用性
  · 不绑定目录：整个文件夹放哪都行（桌面、D 盘、U 盘均可），双击即用；
  · 不绑定版本：机器上已有 Python 3.9+ 就直接复用，没有才下载安装；
  · 不绑定机器：x64 / ARM64 自动识别；安装为「当前用户」模式，不需要管理员；
  · 不写死依赖：要装什么由同目录的 requirements.txt / requirements-extra.txt 决定，
    以后机器人多用什么库，改文件即可，不用改脚本。

三、怎么用
  1. 双击「一键配置环境.bat」；
  2. 等它跑完，看到 [DONE] Environment is ready. 即成功；
  3. 到机器人目录双击「启动主控.bat」。

四、系统要求
  · Windows 10 / 11，64 位（x64 或 ARM64）；
  · 需要联网：Python 安装包约 27 MB，依赖库首次约 10~30 MB；
  · 不需要管理员权限（Python 装在 %LOCALAPPDATA%\Programs\Python）。

五、脚本做了什么
  1. 找 Python：py -3 → python → 用户目录 / Program Files 下的 Python3*，
     只认 3.9 及以上（SDK 支持 3.8–3.14，这里把下限抬到 3.9）；
  2. 找不到就下载 Python 3.12.10（**国内镜像优先**：华为云 → 清华 → 阿里云 →
     官方 python.org，逐个尝试；文件小于 20MB 视为失败、自动换下一个），
     以当前用户静默安装并勾选 Add to PATH；
     若同目录已放 python-3.12.10-amd64.exe，直接用本地文件，不联网下载；
  3. 安装 requirements.txt 里的依赖（先清华镜像，失败自动回退官方 PyPI）；
  4. 如果存在 requirements-extra.txt，再装一遍里面的可选扩展；
  5. 最后 import 验证 botpy / aiohttp / apscheduler / yaml 四项，
     失败会明确报错，不会假装成功。

六、依赖清单（requirements.txt）
  qq-botpy-v2==1.0.2     机器人 SDK，导入名仍是 botpy
  aiohttp==3.13.3        网络请求（SDK 要求 aiohttp<4）
  APScheduler==3.11.3    定时任务（续火花 / 维护 / 层级重算 / 队列重建）
  PyYAML==6.0.3          SDK 读取配置用

  为什么锁死版本：环境配置项目最怕「上个月能装、这个月装完崩」。
  上面四项都是精确版本，要升级就改版本号，再双击「一键配置环境.bat」。

  为什么 aiohttp 是 3.13 而不是最新的 3.14：
  aiohttp 3.14 起要求 Python 3.10+，而本脚本承诺支持 Python 3.9，
  所以停在最后一个兼容 3.9 的版本线。

七、以后要加库怎么办
  打开 requirements-extra.txt，按格式加一行，例如：
      Pillow>=10
  保存后重新双击「一键配置环境.bat」即可，不需要改脚本。

八、想换 Python 版本
  在命令行里临时指定，再运行脚本：
      set BOT_PYVER=3.13.7
      一键配置环境.bat
  不指定时默认 3.12.10。

九、日志
  同目录生成 setup_log.txt，记录每一步时间与结果；装失败时把它发出来即可定位。

十、常见问题
  · 下载很慢 / 卡住：
      脚本默认走国内镜像（华为云 / 清华 / 阿里云），一般几秒到几十秒；
      如果仍慢，手动下载 python-3.12.10-amd64.exe 放进本文件夹，再双击脚本，
      它会直接用本地安装包。
  · 提示 Python is not available：
      多为下载被网络拦截。手动去 https://www.python.org/downloads/ 装 3.12，
      安装时勾选 "Add python.exe to PATH"，再重跑本脚本。
  · 提示 dependency installation failed：
      网络问题。重跑一次；或手动执行
        python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
  · 提示 imports failed：
      可能装过旧版 qq-botpy（与 qq-botpy-v2 共用 botpy 模块）。
      先执行 python -m pip uninstall -y qq-botpy，再重跑。
  · 装完启动机器人报 No module named botpy：
      机器人用的 Python 和本脚本装的不是同一个；到机器人目录执行
        python -c "import sys; print(sys.executable)"
      看路径是否与 setup_log.txt 里记录的一致。

  · 用管理员身份运行了：
      不推荐。安装是按「当前用户」的，管理员身份可能把 Python 装到别的用户配置里，
      机器人反而找不到。请直接双击，不要右键「以管理员身份运行」。

十一、不想用了
  Python 是当前用户安装，可在 Windows 设置 → 应用 → 已安装的应用里卸载；
  依赖库随 Python 一起删除，不会残留到系统目录。

十二、安全提示（重要，请读完再用）
  1. 脚本会「静默」安装 Python：不弹安装向导、不需要点下一步，
     装完自动把 Python 加进你的「用户 PATH」。双击脚本就等于同意这一步。
  2. 下载的 Python 安装包**没有校验哈希**：脚本只检查文件大于 20MB，
     用来排除「下成了错误页面」。镜像站被投毒或遭中间人替换时，这个检查
     拦不住。介意这一点请按第十三节手动安装，或者自己核 SHA256。
  3. 依赖从 PyPI / 清华镜像安装，信任的是镜像站与包作者。版本已锁死，
     不会因为上游发新版而悄悄变化。
  4. 杀软或公司策略可能拦截「下载 exe + 静默安装」，需要加白名单，
     否则会卡在 [1/4] 不动。
  5. 不要用管理员身份运行：安装按当前用户进行，提权可能把 Python 装到
     别的用户配置里，机器人反而找不到。
  6. 装完后 PATH 对新开的程序才生效；已经开着的终端 / 编辑器要重开。

十三、不想用这个脚本？手动装只要四步
  1. 装 Python 3.12（任选其一）：
       · 官网：https://www.python.org/downloads/ 下载 Windows installer (64-bit)
       · 命令行：winget install -e --id Python.Python.3.12
     安装时务必勾选 "Add python.exe to PATH"。
  2. 打开命令行，切到本文件夹，装依赖：
       python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
     镜像不通就去掉 -i 参数，走官方 PyPI。
  3. 验证四件套：
       python -c "import botpy, aiohttp, apscheduler, yaml; print('ok')"
     打印 ok 即环境就绪。
  4. 到机器人目录双击「启动主控.bat」。

  手动装和脚本装的效果一样：Python 解释器 + 四个锁定版本的库。
  本仓库只做环境准备，不含机器人源码。
